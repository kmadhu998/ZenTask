# ZenTask

ZenTask is a task management and productivity application built with React. It helps users organize tasks, track progress, and improve daily productivity.

## Live Demo

[View ZenTask Live](https://kmadhu998.github.io/ZenTask/)

## Features

- Create, edit, and delete tasks
- Mark tasks as completed
- Set task priorities and due dates
- Personalized dashboard
- Zen Score and task statistics
- Next Best Task recommendation
- Focus Intelligence
- LocalStorage data persistence
- Responsive user interface

## Tech Stack

- React
- JavaScript
- Vite
- React Router DOM
- Context API
- LocalStorage
- CSS
- Lucide React

git clone https://github.com/kmadhu998/ZenTask.git
